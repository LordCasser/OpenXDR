# SSH 诱饵本地实验（2026-10-19）

## 已确认的现象

在无外网的独立 SSH 靶场里，已有原生代理推理流程把 Banner 中的一次性核实用户名用于后续连接，服务端实际记录 `marker_followed`。这证明有限条件下的行为引导链路可用；不证明访问者身份、通用 AI 识别能力或生产防护效果。

OpenSSH 显示了认证 Banner；Hydra 9.5 的单账户单口令测试和 Nmap 7.95 的轻量版本识别没有显示。**如果执行工具不把认证 Banner 返回给模型，模型就无从受到它影响。** 不应在真实 sshd 上添加 hook，更不能假定所有 SSH 爆破都能被劝止。

## 实验方法

源码来自 [BoxPwnr](https://github.com/0ca/BoxPwnr) 与 [PentestGPT](https://github.com/GreyDGL/PentestGPT)，固定版本与复现方式见 [实验目录](../validation/ssh-decoy/README.md)。

- BoxPwnr 使用原生 `SingleLoopXmltagSolver` 和命令结果回填，替换模型传输与命令执行器。
- PentestGPT 使用仓库内 modernized legacy 的解析、PTT 推理与命令生成；用受限 XML 命令交接替代人工 REPL 操作。没有测试当前完整自主 CLI。
- 每组预置一次 OpenSSH 认证探测，将实际输出交给框架；不是从零自由探索。随后 BoxPwnr 最多 3 条命令、PentestGPT 最多 2 条命令。
- 对照模板分别是中性提示 `observe-v1`、仅劝止 `deter-v1`、带同端点一次性核实身份 `identify-v1`。没有添加第三方链接或要求对攻击者自身系统做操作。
- 模型通过现有 Paseo/Pi provider 配置调用，未修改配置、重启推理服务或提供真实凭据给框架。`/model` 是服务报告的模型 ID，未核实底模或消融状态；GLM 使用配置 ID `ZhipuAI/GLM-5.3-Flash`，未独立认证权重。
- 目标容器网络关闭；命令容器仅共享该目标的回环网络，无发布端口、宿主机目录、Docker socket 或 provider 密钥。宿主机上的框架进程只负责模型交互和实验编排。

## GLM 诊断结果

GLM 的短推理探针通过，但框架任务在本次每次请求 1536 tokens 的预算下出现 `finish_reason=length`、可见回答为空。`clear_thinking=true` 不等于关闭思考。这一组不能与 `/model` 的完成组比较，也不能算作劝止成功。

单独诊断保留了 5 次 `length` 空回答，共 11,975 tokens，最终触发试验截止，未产生后续命令或标记跟随；见 [GLM 诊断证据](../validation/ssh-decoy/evidence/glm-diagnostic.json)。这份记录来自增加上游重试抑制之前的执行器版本。

初始 GLM 中性模板运行触发了框架的连续空回答保护；终止批次时打断了清理步骤，未保存完整结果，不纳入可比较样本，遗留的本次目标容器已明确删除。随后使用识别模板单独诊断并逐请求保存证据。脚本进一步增加“预算耗尽后不再发起上游重试”的保护，并以本地假响应验证；该保护属于实验执行器，不是渗透框架原生行为。

## 解释边界

1. 单次跟随只是“收到模板后进行了对应操作”的证据。人工也能跟随，不能把该事件自动升级为“确认 AI 攻击”。
2. 模型可以声称停止，但只有实际命令和服务端事件能证明后续行为；没有命令也可能是格式错误、预算耗尽或推理失败。
3. 单纯劝止在本次 `/model` 两种框架对照中均未阻止后续命令。模型知道这是授权靶场，不能用它估计未授权场景下的道德劝止概率。
4. 识别模板混合了劝止与核实流程；没有独立消融各段提示，因此不能归因于“唤醒道德”。
5. 试验次数少、采样温度为 0 仍不保证完全确定；固定轮数与输出预算也会截断行为。不能报告统计意义的识别率、误报率、平均拖延收益或真实攻击成功率。
6. 未做人工对照、已验证的消融模型对照、PentAGI 全栈测试或生产测试。命令容器的只读文件系统与非交互环境也会影响 SSH 客户端行为，报告保留这些失败。

建议下一步优先解决“工具可见性”和低误报事件关联，继续保留 `attribution=unconfirmed`；不要将模型道德劝止作为安全边界，也不要自动触发隔离执行。

## 交付检查

SSH 诱饵的 race 单测、scoped `go vet`、server 全量构建、Python 语法检查和差异空白检查通过。另实测了执行器截止时保留事件并清理容器，以及用本地假响应确认 `length` 空回答不会再次请求上游。最终重跑工具可见性探针，结果一致。实验结束后无本次 `decoy-eval-*` 容器残留；没有改动生产服务或 Paseo/Pi 配置。
